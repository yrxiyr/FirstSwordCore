# 初锋・核心

**初锋**的附属模组。给初锋加上「核心」词条系统。

主模组本身不改数值——不装这个模组，初锋的平衡和原来完全一致。

- Minecraft **1.21.1**
- NeoForge **21.1.x**
- 必需：**初锋 `firstsword` 1.7.0+**

## 怎么用

核心是打在剑上的强化词条。**副手拿着初锋，主手拿着核心，右键**。

附魔和自定义名字都不会丢，只多一条词条。一把剑可以装多个核心，效果叠加。

## 核心一览

| 核心 | 效果 | 获得方式 |
|---|---|---|
| 汇聚核心 | 流星群冷却 -10 秒，彩虹雷伤害 +6 | 击杀 1% 掉落，每人一次 |
| 毁杀核心 | 攻击力 +4，瞬闪斩伤害 +6 | 合成 |
| 顷火核心 | 被流星命中的怪灼烧 7 秒（每秒 8 点）；自身获得 12 秒抗火 + 12 秒伤害吸收 | 合成 |

### 顷火核心

```
恶魂之泪  黑曜石  恶魂之泪
 黑曜石     罪    黑曜石
恶魂之泪  黑曜石  恶魂之泪
```

「罪」：任意生物被玩家击杀时 1% 掉落，每人一次。

## 安装

1. 安装 Minecraft 1.21.1 与 NeoForge 21.1.x
2. `mods` 文件夹里放**两个** jar：
   - `firstsword-1.7.0.jar`
   - `firstsword_core-1.0.0.jar`

创造模式物品栏 →「材料」页可以直接取到所有物品。

## 从源码构建

需要 JDK 21。这个工程依赖主模组的 jar，所以要先构建主模组：

```bash
../FirstSword/gradlew build
./gradlew build
```

产物在 `build/libs/`。
