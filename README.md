# 初锋・核心

**初锋**的附属模组。给初锋加上「核心」词条系统。

主模组本身不改数值——不装这个模组，初锋的平衡和原来完全一致。

- Minecraft **1.21.1**
- NeoForge **21.1.x**
- 必需：**初锋 `firstsword` 1.9.7+**

## 怎么用

核心是打在剑上的强化词条。**副手拿着初锋，主手拿着核心，右键**。

附魔和自定义名字都不会丢，只多一条词条。一把剑可以装多个核心，效果叠加。

## 核心一览

| 核心 | 效果 | 获得方式 |
|---|---|---|
| 汇聚核心 | 流星群冷却 -10 秒，彩虹雷伤害 +6 | 击杀 1% 掉落，每人一次 |
| 毁杀核心 | 攻击力 +4，瞬闪斩伤害 +6 | 合成 |
| 顷火核心 | 被流星命中的怪灼烧 7 秒（每秒 8 点）；自身获得 12 秒抗火 + 12 秒伤害吸收 | 合成 |
| 摧灭核心 | 流星群追加 5~6 颗中型流星（36 点 / 半径 3）；法阵范围 ×1.5，小流星数量同步增加 | 第一次触发不死图腾，每人一次 |
| 破袭核心 | 点按（不蓄力）流星键不召唤流星，改为获得 12 秒抗性提升 II + 力量 II，并储存 3 次爆裂斩（左键命中时在目标身上爆炸：12 点 / 3×3，不破坏地形） | 第一次进入下界，每人一次 |
| 牵星核心 | 大流星落地前展开半径 8 格的引力场，把怪拽向圆心并减速 50%；被拽住的怪吃流星伤害 ×1.4 | 末影珍珠×4 + 恶魂之泪×4 + 下界之星 |
| 回响核心 | 瞬闪斩可存 3 次（冷却不变）；每命中一目标回 2 点血，单次最多 6 点 | 第一次一刀刮到 ≥3 个目标，每人一次 |
| 奏鸣核心 | 快速连按「左键→右键→左键」触发组合技：在瞬闪斩的同时，沿冲刺方向分三波炸开横向彩雷，铺满 15×7×7 的长方体（每波 20 道，落雷光柱横放）；瞬闪斩/组合技给 8 秒速度 II + 急迫 II，组合技额外给跳跃提升 II + 生命恢复 II | 第一次进入末地，每人一次 |
| 森罗核心 | 彩虹雷无视方块（在当前高度生成并向下贯穿，下界/洞穴/室内都能落雷），落点半径 ×1.4（30 → 42 格） | 煤、铜、铁、金、钻石、绿宝石、青金石、红石、远古残骸各 1 |

## 安装

1. 安装 Minecraft 1.21.1 与 NeoForge 21.1.x
2. `mods` 文件夹里放**两个** jar：
   - `firstsword-1.9.7.jar`
   - `firstsword_core-2.0.0.jar`

创造模式物品栏 →「材料」页可以直接取到所有物品。

## 从源码构建

需要 JDK 21。这个工程依赖主模组的 jar，所以要先构建主模组：

```bash
../FirstSword/gradlew build
./gradlew build
```

产物在 `build/libs/`。
